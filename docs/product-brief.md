# Portfolio Website

## Purpose

A visual-first portfolio for a professional photographer and videographer.

## Primary audiences

- Prospective clients
- Creative agencies
- Production companies
- Collaborators

## Primary actions

- View selected work
- Explore an individual project
- Understand the creator's style
- Contact the creator

## Initial routes

- /
- /work/[slug]
- /about
- /contact
- /admin

Projects list is a homepage overlay (not `/work`).

## Initial scope

The first implementation will use local mock data.
Supabase and the CMS will be added after the public portfolio structure is stable.
